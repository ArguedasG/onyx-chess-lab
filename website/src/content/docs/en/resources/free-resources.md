## Import a PGN into Onyx

1. Download the file and unpack it if it comes as `.zip`, `.7z` or `.bz2`.
2. In **Databases**, press **+** and choose the **Local** tab.
3. Give it a name, select the PGN file and press **Convert**.

Large files take a few minutes; you can keep using Onyx meanwhile.
