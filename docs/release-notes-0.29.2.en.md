# Onyx Chess Lab 0.29.2

Onyx now reads its download catalog from its own repository, Open board on an opening line goes straight to that line, and confirmations use Onyx's own dialog instead of the system's.

## Download catalog

- The lists of databases, puzzles and engines you can download now come from Onyx's own repository on GitHub instead of En Croissant's server. You see the same entries and files download from the same places as before.
- A broken or outdated link can now be fixed in the repository, without waiting for a new version. Without a connection, Onyx still offers the copy that ships with the app.

## Openings

- Open board on a line of a repertoire section now opens the board at the end of that line instead of at the start of the section, so the line is easy to find. If the section was edited since, it stops at the furthest move of the line that remains.

## Confirmations

- Deleting a player card, a twin, a saved analysis or a training position, emptying the mistake queue, restoring a backup, replacing a file when exporting and clearing saved data now ask in an Onyx dialog, in your language and theme, instead of the operating system's window.
- When the action deletes or replaces something, the confirm button is red and Cancel is the one selected, so pressing Enter by accident does nothing.

Your repertoires, studies, books, training progress, databases, analyses and settings are preserved.
