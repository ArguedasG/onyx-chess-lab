# Onyx Chess Lab 0.29.3

You can now use your own piece set from a folder of images, the Endgames screen is fully in English, PGN comments no longer squeeze the tactics buttons, and the Woodpecker cycle clock stops while a solved puzzle waits for the next one.

## Piece sets

- Settings → Piece Set has a new Load from a folder… button. Choose a folder with the twelve piece images (PNG, SVG or WebP) named wP, wN, wB, wR, wQ, wK, bP, bN, bB, bR, bQ, bK, and the set appears under Your sets, named after the folder.
- Onyx keeps its own copy of the images, so the set keeps working if you move or delete the folder. Loading the same folder again updates the set, and Remove this set takes it away.
- If an image is missing or larger than 2 MB, Onyx says which one and keeps your current pieces.

## Endgames

- The Back to the endgame list button, during the game and on the result screen, was always in Spanish. It now follows the app's language.

## Tactics

- With PGN comments shown, the Storm, streak or countdown button and the Next puzzle button were squeezed into thin strips. They keep their size now, and the side panel scrolls when the comments are long.
- In Woodpecker, the cycle clock stops as soon as you solve a puzzle and starts again with the next one, so the time spent reading the result no longer counts toward the cycle.

Your repertoires, studies, books, training progress, databases, analyses and settings are preserved.
